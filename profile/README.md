## How A Briefed Folder Behaves From Then On

Underneath everything sits one straightforward idea: a location plus an ordered list of instructions. You nominate
the location, then describe the files you care about using the same kind of picker Mail uses for its own rules —
extension, kind, size, name fragment, how old the item is, which website delivered it, or whose message carried
it in. Those tests stack, so "spreadsheet, under a megabyte, sent by the bookkeeper" is one line of setup rather
than a weekend spent learning a scripting language.

Beneath each set of tests you list what should happen. Relocating is the obvious verb, but the same menu offers
renaming by pattern, colour labelling, keyword stamping, comment writing and compressing into an archive, and a
single match can trigger several of them in sequence. Instructions are read from the top down, which is how two
overlapping descriptions get resolved: the more specific one goes above. Because a helper process does the
watching, hazel for mac keeps working with its window shut and its icon nowhere in sight.
